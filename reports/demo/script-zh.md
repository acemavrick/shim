# Shim × BeFreed：54 秒演示

1. 01_problem（8 秒）

网站适合人类浏览。但给智能体用，还需要参数明确、可以重复调用的工具。

2. 02_website（8 秒）

以 BeFreed 为例，我们打开一本书，查看标题、作者和分类。这里是真实网站。

3. 03_incremental（9 秒）

Shim 一边探索，一边显示候选工具。只有验证成功才可调用。这里回放真实编译记录，压缩了等待。

4. 04_schema（9 秒）

加载已经完成的编译结果。书籍详情变成一个工具，只需要提供书籍标识，输入和提取规则都已保存。

5. 05_call（12 秒）

现在调用真实网站，返回成功状态和结构化记录。之后调用只发网络请求，不需要模型再次操作浏览器。

6. 06_export（8 秒）

同一份验证结果可以输出 MCP、OpenAPI 和网站说明。把人类浏览流程，变成智能体可复用的接口。
